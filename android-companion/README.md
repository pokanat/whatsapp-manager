# Android SMS Companion (local prototype)

Open the **android-companion** folder in Android Studio on Windows and build/install the app on a phone you own. Grant the RECEIVE_SMS permission in the app. The app receives ordinary incoming SMS and displays them **only on the same phone**.

Authentication/verification messages are filtered on a best-effort basis; do not use this prototype to store sensitive messages. No internet permission, cloud upload, remote dashboard sync, WhatsApp registration, or WhatsApp message access is included. Android SMS permissions and background delivery are subject to OS/device policies. This prototype has not yet been compiled or tested on a physical device.
